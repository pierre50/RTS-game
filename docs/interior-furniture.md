# Catalogue du mobilier intérieur

Dans un bâtiment ou une grotte, ouvrir **Construction → Mobilier**. Le placement utilise l’aperçu et l’orientation existants, protège les accès et refuse de couper les passages. Les tapis et peaux restent traversables.

Les nouveaux bâtiments du héros sont vides, sauf le coffre permanent du **Granary** et du **StoragePit**. Les bâtiments IA conservent leurs presets. Le choix est sauvegardé indépendamment du propriétaire actuel. Le contenu des anciennes sauvegardes est conservé, sans ajout automatique d’éclairage chez le héros.

Les objets utilisent leurs coûts et fonctionnalités existants : les objets décoratifs ne deviennent pas des ateliers de production.
