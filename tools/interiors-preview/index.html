Affichage

Aménagement des intérieurs neufs. Les meubles déjà placés dans une sauvegarde sont conservés. Glisse les meubles puis clique sur « Enregistrer pour le jeu ». Les positions sont communes aux deux orientations, pour le bâtiment et le niveau sélectionnés. Aucun chargement de sauvegarde. Sans personnages, chevaux, ombres ni éclairage dynamique. Les grottes ne font pas partie de ce rapport.

Après une modification du jeu, relance pnpm interiors:preview puis recharge cette page.
